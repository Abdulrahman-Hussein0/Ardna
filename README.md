# Ardna
أرضنا، ازرع اللي البلد محتاجه

شات بوت بيقترح على المزارع يزرع إيه في محافظته، وإيه الفايض اللي ممكن يتصدّر، مع تقدير تقريبي للأرباح وخطة لتوزيع الأرض حسب عدد الفدادين.

بيشتغل إزاي

أولاً، بنقارن إنتاج مصر بالمعروض المحلي لكل محصول عشان نعرف العجز والفايض.

ثانياً، بنقيس مدى مناسبة حرارة المحافظة وحموضة تربتها وملوحتها لكل محصول.

ثالثاً، بنضرب العجز في الملاءمة، فبيترشح المحصول اللي البلد محتاجه ومناسب للأرض.

رابعاً، بنراعي إن زراعة الأرز مسموحة في محافظات محددة بقرار وزارة الري.

خامساً، بنوزع الأرض على موسمين، شتوي وصيفي، ونحسب ربح تقريبي.

طريقة التشغيل

افتح النوت بوك في Google Colab، وارفع ملف بيانات الإنتاج والمعروض لما الخلية تطلبه، وبعدين شغّل الخلايا بالترتيب. آخر خلية بتفتح الشات.

المكتبات المستخدمة: pandas, scikit-learn, gradio, kagglehub

تنبيه مهم

المشروع ده نسخة تجريبية. الأرقام تقديرات مبدئية ولازم تتراجع قبل أي استخدام فعلي، وده يشمل حرارة وحموضة وملوحة كل محافظة، وإنتاجية المحاصيل وأسعارها وتكاليفها، ودول التصدير. الأرباح تقريبية جداً، والفعلي بيتغير حسب السعر والتكلفة والموسم.

خطوات جاية

استبدال الأرقام التقديرية ببيانات حقيقية، وتحميل الأسعار ودول التصدير من ملف بدل ما تتكتب في الكود، وإضافة محافظات ومحاصيل أكتر.
